如果你也做「トリックハート」的角色替换，下面这些数字可以直接拿来当起点，省掉 P1 的大部分摸索。原PV请自行合法获取；数据只有时间和文字描述，没有任何画面。

## 2. 两个角色（sourceRole）

- **magician**：钻头双马尾；黑色高礼帽，带白色菱形纹、红色帽带和白羽毛；**长到臀部的红色西装外套（没有燕尾）**；白衬衫、黑领结；白手套配橙色翻袖口；黑短裤；**腿部左右不对称**（她自己的右腿是黑白条纹过膝袜，左腿是到膝下的黑袜，大腿上另有一圈独立的黑腿环）；红短靴，靴口有白色锯齿翻边；脸颊上有小红心妆。
- **casual**：披发；宽大的灰色开衫配黄 T 恤；橙黄色的鞋。**f3543 起**换成黄外套加斜挎包；**f3584 起**头发扎成钻头，并插着白羽饰（就是魔术师礼帽上那根）；卡套里装着红心 A。

## 4. 抖动（line boil）

- 大多数静止镜头是 A/B 两张重描、每 6 帧交替，位移中位数 1.3–3.2 px。
- 每个镜头的实测切换帧、相位（holds）和例外（独立图层时钟、额外换稿事件）都在 `shots.json` 每一镜的 `boil` 字段里。
- 用法见 [docs/04](04-线条抖动与质感还原.md)。

## 5. 数据字段

`shots.json` → `shots[]`：

| 字段 | 含义 |
| --- | --- |
| `shotId`、`startFrame`、`endFrameExclusive` | 镜头编号和区间（左闭右开） |
| `sourceRoles` | 这一镜出现的原PV角色 |
| `sourceAction` | 原PV动作节点的文字描述（含关键帧号） |
| `props` | 道具、动物、画框、文字等元素 |
| `boil.holds` | `[{startFrame, endFrameExclusive, phase}]`：每一段用哪一张重描 |
| `boil.boilFrames` | 发生整幅重描的帧 |
| `boil.poseChangeFrames` | 真正换姿态的帧（不算抖动） |
| `boil.layerSchedules` / `boil.phaseSwitchFrames` | 少数镜头的特殊节奏 |
| `boil.status` | `measured` 或 `no-character` |

`pose-events.csv`：`frame, shotId, sourceRoleOrObject, event, state`。

数据来自一次实战的测量和人工复核，可能仍有个别误差；用之前抽查几个关键帧。
