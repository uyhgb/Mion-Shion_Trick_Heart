# 02 角色卡编写指南

角色卡是 P2 的输入，也是之后每一张原画的身份依据。写得好，母版一两轮就能过；写得含糊，母版会反复返工。空白模板见 [`templates/character-card.md`](../templates/character-card.md)，实战示例见 [`examples/mion-shion/character-card.md`](../examples/mion-shion/character-card.md)。

## 1. 先把原PV的两个角色拆清楚

在设计你的角色之前，先把原PV两位テト的外观结构**逐项写下来**，并为每一项标注源帧证据。服装结构要沿用原PV（这样手、道具的接触关系才能复用），所以这一步漏一项，后面就要返工一次。

实战中漏掉、事后返工的两项：

- 魔术师的外套是**长到臀部的西装外套，没有燕尾**。早期文档凭印象写成了「燕尾服」，母版就画出了燕尾。
- 魔术师的两条腿**不对称**：她自己的右腿是条纹过膝袜，左腿是到膝下的黑袜，大腿上另有一圈独立的腿环。母版画成了过膝黑长袜，和合成帧对不上，作者还以为是合成图出了错。

本曲两个角色的结构清单见 [docs/06](06-魔术之心原PV实测数据.md)。

## 2. 素材准备与人工标注

| 要点 | 说明 |
| --- | --- |
| 主身份源只选一个版本 | 原作立绘、动画、重制版不要混着当身份参考 |
| 需要的视角 | 正面全身、背面或侧面（看发型扎法和发饰背面）、面部、鞋袜；同一套衣服的多种表情最好 |
| 逐张标注 | 用途（身份、服装、鞋、背面……）、禁用项、光照是否可信、是否含敏感内容 |
| 取色 | 只从光照正常的立绘取；夜景、滤镜 CG 只看结构 |
| 敏感内容 | 带伤、血、倒地之类的 CG，只用于标注过的那一项用途（比如只看鞋），绝不借用画面内容 |
| 只当参考 | 游戏或动画素材只进生图参考，绝不直接贴进成片，也不要放进开源仓库 |

小技巧：游戏立绘常有同一表情的「闭嘴 / 半开 / 张开」三张口型差分，可以直接对应原PV的张嘴事件。

## 3. 参考职责

写进每一条生图提示的开头：

| 参考 | 负责 | 不负责 |
| --- | --- | --- |
| 原PV源帧（该镜头裁切） | 构图、头部尺度、朝向、手腕位置、接触点、留帧 | 角色身份 |
| 已冻结的角色母版 | 发型、脸、服装、配色 | 动作 |
| 画风规范（从原PV抽取） | 线条、上色、纹理 | 身份、动作 |
| 官方立绘与 CG | 身份细节的原始依据 | 画风；不进合成 |

## 4. 身份档案怎么写

每个角色分三块：

1. **hardConstraints（不可改）**：发型结构（扎点、长度、分缝、发饰的位置和数量）、瞳色、脸型、标志性配饰及其所在侧、身高与另一位角色的关系。
2. **softConstraints（可风格化）**：线宽、纹理、阴影层数。
3. **简化后必须保留的身份标志**：原PV是扁平简笔画，细节会被大量删掉。先列出「删到最简也不能丢」的东西，例如马尾的扎点、两侧的小蝴蝶结、瞳色、领结至少两三道条纹、胸前的心形徽章。

每个细节都写明依据哪张参考图；参考里看不到的写 `unknown`，不要编。

## 5. 服装设计法：原PV结构 + 角色配色

角色要穿原PV的衣服（例如魔术师装）时：

- **结构照原PV**：帽子、外套剪裁、手套、袜、鞋。这样只露手的镜头能直接沿用原PV的手，持物接触也能复用。
- **配色和标志取自角色**：从角色原有服装里挑两三个标志色或部件（例如马甲、领带），加到原PV的结构上。
- **做 2–3 个候选**，都放在原PV的背景色上试一张，由作者选。实战中作者选了「保留原PV红外套 + 淡黄马甲 + 红长领带」，长领带比领结更像角色本人。
- 原PV的妆容和配饰（例如脸颊上的小红心）可以保留，当作舞台妆。

角色穿自己的衣服时，就用官方服装，只按原PV的画风简化。袖长、鞋袜这类和原PV不一样的部件，要在角色卡里写清楚，后面每个露出这些部位的镜头都会用到。

## 6. 表情：照源片，只改画法

- **原PV的表情事件（睁眼、张嘴、眨眼、半睁眼）一律保留。** 不要为了剧情去改表情，比如把「惊讶张嘴」改成「眼神空洞」。剧情靠道具、构图和顺序来讲，不靠改动画。
- 「演法」只决定同一个表情怎么画得像这个角色，比如同样是笑，A 咧嘴，B 抿嘴。
- 做一张表情参考对照：本片要用的每种表情，对应到哪张官方立绘。

## 7. 两个角色要像什么、不像什么

- 同一基线并排，检查头顶高度和头身比。
- **同脸角色**（双胞胎、同一人的两种形态）：先定一张「共用脸」，第二个角色在它的基础上只改发型、配饰和表情。验收方法：遮住头发后，两张脸应该分不出来。
- 判断差异大不大，要做按双眼对齐的叠线对比，不要只凭「看着有点不一样」。实战中执行 AI 报告「眼距、下巴有细差」，叠线后发现几乎重合，第一版直接可用，省了一整轮返工。
- 配饰大小不要让执行 AI「自动收小」。实战里一句「缩小到接近源片比例」让缎带缩得太小，作者不满意，只好改回去。

## 8. 母版阶段的流程建议

1. 先出正面全身，再按分镜实际需要补视角；不要默认三视图全画。
2. 每张母版最多尝试 4–6 次，落选也登记。
3. 修订时只改被点名的问题；改不动就停下报告，不要越改越多。
4. 作者批准后计算哈希并冻结，写正式冻结清单；旧版标 superseded，不删除。
5. 一帧合成试画只用来检查，不当母版；它在逐镜生产时会重画。

## 9. 母版验收清单（模板）

- [ ] 双人同基线并排，身高和头身比符合设定
- [ ] 同脸角色遮发后分不出来（非同脸角色：脸型差异符合原作）
- [ ] 发型结构、扎点、发饰数量和位置与参考一致；帽子没有压住发型
- [ ] 不对称特征在正确的一侧；没有水平翻转
- [ ] 服装结构与原PV逐项一致（外套长度、袖口、袜、鞋），配色符合所选候选
- [ ] 简化后的身份标志都在
- [ ] 画风接近原PV，但角色一眼认得出
- [ ] 透明背景干净、无白边，主体像素足够，不是低清图放大
