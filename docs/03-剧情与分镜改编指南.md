# 03 剧情与分镜改编指南

角色替换类手书的剧情，不是另起一套分镜，而是**在原PV的镜头上重新解读**。时间轴、动作、构图都不动，能改的只有三样：谁来演、穿什么，以及少量道具和纹样上的彩蛋。实战示例见 [`examples/mion-shion/story-and-storyboard.md`](../examples/mion-shion/story-and-storyboard.md)。

## 1. 顺序：先粗写，实测后再改写

1. **粗看原PV**：每 3 秒抽一帧拼成联系表，列出主要元素和大致顺序。
2. **写第一版叙事**：歌词意象和角色关系的对应表、角色映射、四幕情绪弧、彩蛋分级。这一版允许是推测。
3. **P1 实测后回填**：执行 AI 拆完镜头，会给出每个元素的真实帧区间和持有者。凡是和叙事冲突的地方，**改叙事，不改源片**。
4. **SP1 定稿叙事**：作者确认后写进决策记录。

实战中第一版有两处被实测推翻：

- 以为第二段副歌的红心 J 在魔术师手里，实测是散发角色拿着。最后把牌的含义改成「谁拿着牌，就是她现在顶着的身份」，结果比原稿更顺。
- 原PV结尾，散发角色把头发扎成了魔术师的钻头。粗看时没注意到，实测后变成了全片的点题：她扎起了另一位角色的发型。

## 2. 角色映射

原PV两个角色的分工（详见 [docs/06](06-魔术之心原PV实测数据.md)）：

| sourceRole | 原PV里的样子 | 原PV里的「戏」 |
| --- | --- | --- |
| `magician` | 钻头双马尾、礼帽、红外套、白手套 | 变魔术的人：持牌、硬币变蝴蝶、帽子里变兔子、送花、杂耍；沙发上先醒来，手从对方手上滑开，之后不再出现 |
| `casual` | 披发、宽大开衫 | 被魔术打动的人：惊讶、开心、接住兔子、拿到红心 J；最后独自醒来，扎起钻头，背包出门，卡套里装着红心 A |

选角色时问自己：两人里谁更像「为对方变魔术的人」？谁的结尾更适合「接过对方的样子，独自往前走」？

## 3. 歌曲意象对照表

把歌的核心意象逐条对到你的角色身上（只写自己的话，不抄歌词）。本曲可以用的意象：

- 手掌里的一张牌、仅此一次的秘密魔术
- 「没有机关、没有骗术」的世界
- 不能揭开的「种」（谜底）
- 像谎言一样的真实时光
- 失败过、低着头的过去，也被原谅
- 红心 A 和红心 J
- 落幕，以及最后能笑出来

能把这几个意象对上角色关系里最核心的那件事，剧情就站住了。实战示例里，这件事是双胞胎小时候互换身份的秘密。

## 4. 彩蛋分级

| 级别 | 特征 | 例子 |
| --- | --- | --- |
| A 必做 | 只改牌面、纹样，不加镜头，几乎零成本 | 牌背图案、牌面落位、服装自带的徽章 |
| B 推荐 | 道具换色、帽子内衬、碎片调色 | 杂耍球换成两人的代表色 |
| C 可选 | 要新画道具并跟踪源片动画 | 把原PV的动物换成和原作相关的玩偶 |

v1 只做 A 和 B 级。彩蛋只能放在源片已有可见位置的地方，不要为了彩蛋新增视角。

## 5. 源片里有「变化」的地方，是设计决策点

原PV里角色外观发生变化的地方，例如换衣服、换发型、两人同框，都要在 SP1 由作者单独决定怎么处理。这些地方往往是二创最出彩的点，也是最容易漏的点。处理方案要写进角色卡，作为发型或服装的变体，并注明用在哪几个镜头。

## 6. 表情和情绪

原PV的表情事件全部保留（见 [docs/02](02-角色卡编写指南.md) 第 6 节）。如果剧情想要「痛」，就让牌的落位、两只手的接触与分开、落幕、背影来承担，不要去改动画。

## 7. 红线（建议作为默认值）

- 不改音轨、时间轴和 BPM，不加减镜头。
- 原PV的歌词保留源像素；任何文本文件里都不写歌词全文，中文字幕用你自己的译文。
- 不画血腥画面；原作里的敏感设定只以道具纹样的形式暗示。
- 同脸角色的脸型和身高必须一致。

## 8. 发布

- 封面可以用两人对称构图，各拿一张关键牌。
- 简介里写明：原曲 MIMI feat. 重音テトSV、绘・动画 3774.、角色原作及权利方、AI 生成、个人非商用。如果用了本工作流，请注明本仓库和洛琪希版工程。
