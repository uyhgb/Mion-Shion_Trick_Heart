# 04 线条抖动与质感还原（P4s）

这是整条工作流里性价比最高的一步：**不调用生图，只做确定性后处理**，就能让换上去的人物和原PV的手绘质感融成一体。实战里双人沙发那个长镜头，处理前人物一动不动、和背景割裂，处理后浑然一体。

工具：[`tools/pv_boil.py`](../tools/pv_boil.py)；给执行 AI 的 Skill：[`skills/pv-line-boil/SKILL.md`](../skills/pv-line-boil/SKILL.md)。

## 1. 两个通病

1. **人物不抖。** 3774. 的原PV是手绘动画，静止的镜头里整幅画（包括人物）其实是两张略有不同的重描稿，按固定节奏来回切换（俗称 line boil）。背景在抖，换上去的人物却是同一张图一直不动，于是像贴上去的。
2. **线条太干净。** 生成的原画线宽均匀、有轻微渐变，和原片潦草的线不搭。

## 2. 为什么不用生图补

- 抖动要的是「同一张画的轻微重描」，生图给的是「另一张画」：五官、发丝、衣褶每次都会变，放进动画里就成了闪烁，不是抖动。
- 量太大：全片人物帧上千，每张都可能走样、被拦截或返工。
- 这种变化其实可以计算出来：把同一张冻结原画按固定规则轻微扭动，就是一张「重描稿」，身份永远不会走样。

只有「细节密度本身太高」（线条太多太碎）是后处理去不掉的，这种情况只对少数镜头单独重画。

## 3. 先测：原PV的抖动规律

对每个镜头，在人物所在区域内逐帧做差分：

- 大面积同时变化的帧 = 一次「整幅重描」；
- 小面积变化（星光、睡眠符号、文字）不算；
- 真正的姿态切换（换了一张原画）要和重描帧区分开。

本曲实测结论（数据见 [`data/trick-heart-pv/shots.json`](../data/trick-heart-pv/shots.json)）：

- 大多数静止镜头是 **A/B 两张重描、每 6 帧切换一次**（24fps 下约每秒 4 次），第 0 帧和第 12 帧几乎相同。
- 首次切换不一定在镜头第一帧。例如 s004 的第一次切换在 f246，而不是 f240。
- 两次重描之间，线条位移的中位数为 **1.3–3.2 px**，p90 为 **3.4–8.6 px**（1080p 下）。
- 也有例外：有的镜头里两个人物各自有独立的切换节奏；有的镜头的新换稿事件不在 6 帧格点上。**每个镜头都要单独测，不能套一个全局时钟。**

```bash
python tools/pv_boil.py measure --video PV.mp4 --shots shots.json --out boil-schedule.json
```

`shots.json` 是镜头列表：`[{shotId, startFrame, endFrameExclusive, box:[x0,y0,x1,y1], poseChanges:[...], noCharacter?}]`。`box` 取原PV里人物所在的区域；`poseChanges` 填事件表里真正换姿态的帧。对实战中人工审过的三个样镜，这个工具算出的切换帧和 A/B 相位完全一致，位移数值也吻合。

## 4. 再做：每张人物图层的质感变体

处理顺序（全部在**输出像素空间**里做：人物已经缩放、摆进画面之后，裁切和恢复前景之前）：

1. **保护区**：瞳孔、和人物接触的道具（例如抱着的兔子和托住它的手）、源片像素部分不处理。
2. **平涂**：填色压成一套共用调色板（k-means，约 32 色，合并相近色），去掉渐变；线条像素不动。每个像素的颜色偏移有上限，防止腮红、徽章这类小色块被并进旁边的颜色变脏。
3. **线条**：只认接近纯黑、低彩度的细线（最大通道 < 60）；大块黑色填充（帽子、短裤、袜子）不算线条。线宽做低频随机变化（±0.55 px），再加少量柔和断笔。
4. **位移**：一个大尺度（格距约 100 px）加一个小尺度（约 18 px）的平滑随机位移场，按源片实测的位移中位数归一化。两张变体对称取 +F/2 和 −F/2，所以平均位置仍落在冻结原画上。用预乘 alpha 重采样，防止边缘出现黑边或白边。
5. **脸部减半**：眼、嘴附近的位移和线条变化幅度减半（带羽化），防止五官变形。

**确定性**：随机种子由「镜头 | 资产 | 相位 | 用途」做哈希得到。同一相位的所有帧像素完全一致，只在重描帧切换。**不要每帧随机**，那样会变成闪烁。

```bash
python tools/pv_boil.py variants --layer placed_layer.png --key s060.duo \
  --phases A,B --target-median 1.8 --faces '[[820,330,1020,470]]' \
  --protect contact_mask.png --outdir variants/
python tools/pv_boil.py pick --schedule boil-schedule.json --shot s060 --frame 2800   # -> A 或 B
```

接进渲染器（伪代码）：

```python
for frame in shot_frames:
    phase = phase_at(schedule, shot_id, frame)        # 按实测时刻表
    for layer in character_layers(shot_id, frame):    # 姿态切换照原样选原画
        placed = place(layer, frame)                  # 缩放、定位、跟踪
        tex = variants[(shot_id, layer.id, phase)]    # 按 (镜头, 资产, 相位) 缓存
        composite(tex)
    restore_source_foreground(frame)                  # 源片前景、文字照旧
```

## 5. 别漏掉的地方

- **只露手的镜头（沿用源片手部的那类）**：源片的手本来就在抖，不用处理；但新画的部分（前臂、换掉的袖口和服装）**必须跟着同一时刻表抖**，否则会变成静止的补丁。
- **整层替换的特殊镜头**（例如作者手动处理的某一镜）同样要抖。
- **快速换姿态的段落**（例如杂耍，几帧就换一张原画）：抖动只加在同一张原画保持的区间内，换姿态的帧照原样切换。
- **被完全遮挡的帧**（帘幕合上）不用处理。
- 纯源片镜头（没有人物）什么都不做。

## 6. 推广流程

1. **先做三个样镜，作者审**：一个开场替换镜头、一个站立双人镜头、一个长时间静止的双人镜头（最能看出割裂）。每个样镜导出「源片 / 现版 / 质感版」三联同步对比视频，外加一张抖动前后的放大图。
2. **作者认可后，参数文件只读、加哈希**，推广到全片：按时间线分三组并行，每组只写本组目录，个别镜头需要特殊处理时写进本组的覆盖文件并说明原因。
3. **合并**：拼成完整时刻表；用各组的无损帧缓存拼全片；**样镜也要从无损流程重新渲染，不要从已编码的 MP4 解码再编码**；检查分组交界处有没有相位跳闪。

## 7. 验收要看什么

- 原速播放时，人物和背景是否「一起呼吸」，看不出贴图感。
- 脸部有没有变形，尤其是眼睛和嘴。
- 平涂后有没有硬色阶或脏色块，重点看腮红、徽章、渐变大的地方。
- 同一相位的帧是否完全一致（逐帧哈希）。
- 支持区（人物）之外的像素变化应为 0。

## 8. 实战参数（已批准）

| 参数 | 值 |
| --- | --- |
| 位移中位数目标 | 跟随各镜实测，常用 1.4–1.8 px；p90 约 4–4.6 px |
| 位移尺度 | 大 100 px，小 18 px（小尺度中位约 0.5 px） |
| 脸部强度 | 0.5，羽化 12 px |
| 平涂 | 32 簇，合并距离 28，线条保护外扩 3 px |
| 线条判定 | 最大通道 < 60，彩度 < 22；大块黑填充用直径约 9 px 的开运算排除 |
| 线宽变化 | ±0.55 px，变化格距约 55 px |
| 断笔 | 每个墨线像素 0.0012 的概率，σ 1.3 px，衰减 0.72 |

这些是起点，不是常数。换一支PV，要先按第 3 节重新测。
