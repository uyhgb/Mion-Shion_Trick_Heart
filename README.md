# 魔术之心 AI 手书工作流（trick-heart-pv-workflow）

用 AI 把 MIMI「トリックハート」（魔术之心）原PV里的两位重音テト，替换成你喜欢的任意两位角色，做成一支和原PV等长、原音轨、保留 3774. 画面质感的手书二创。

这套工作流来自一次完整的实战：把两位テト换成《寒蝉鸣泣之时》的园崎魅音和园崎诗音，从拆镜头一直做到终稿。仓库里只有方法、规则、模板、工具代码和可公开的示例文字，**不含任何原PV画面、游戏素材、AI 生成的原画或成片**。

> 仅供个人娱乐和学习交流。二创作品请遵守原曲、原PV和角色原作的二创规范，标注出处，不要商用。

## 这套工作流解决什么

| 问题 | 做法 | 在哪里 |
| --- | --- | --- |
| 怎么把原PV拆成可执行的生产计划 | 逐帧拆镜、姿态事件表、图层表、停顿点审批 | [docs/01](docs/01-工作流总览.md) |
| 换成别的角色，角色卡怎么写、母版怎么定 | 参考职责、身份标志、服装「原PV结构 + 角色配色」法、母版验收 | [docs/02](docs/02-角色卡编写指南.md) |
| 剧情怎么贴着原PV写，而不是硬套 | 先写叙事、P1 实测后按源片回改 | [docs/03](docs/03-剧情与分镜改编指南.md) |
| 换上去的人物「一动不动」、线条「太干净」 | **按源片实测的抖动节奏做确定性后处理，不调生图** | [docs/04](docs/04-线条抖动与质感还原.md)、[tools/pv_boil.py](tools/pv_boil.py) |
| 少走弯路 | 实战中每一次返工的原因和修法 | [docs/05](docs/05-踩坑记录.md) |
| 同一首歌，别人已经量过的数据 | 78 镜区间、角色、牌面落位、逐镜抖动时刻表、姿态事件 | [docs/06](docs/06-魔术之心原PV实测数据.md)、[data/](data/trick-heart-pv/) |

## 快速开始

1. **准备环境**：一个能读写本地文件、能运行 Python 和 FFmpeg、能调用生图/改图的执行 AI（实战用的是 Codex）。另装好通用方法 Skill [`ai-handdrawn-video`](https://github.com/waterpro/agent-anime-skill)（作者 waterpro，本仓库不转载其内容），再把本仓库 `skills/` 下的两个 Skill 放进执行 AI 能发现的目录（Codex 为项目内 `.agents/skills/`）。
2. **建项目**：新建工程目录，复制 `templates/` 下的 `AGENTS.md`、`project-brief.json`、`progress-board.md`，按注释填写。
3. **备素材**（你自己合法获取，不进仓库）：原PV视频；两位角色的官方立绘或设定图（同一版本），最好附背面、侧面和鞋子的参考；按 [docs/02](docs/02-角色卡编写指南.md) 第 2 节逐张标注用途。
4. **写叙事和角色卡**：参照 `examples/mion-shion/`，用 `templates/character-card.md` 写你的角色卡。
5. **按阶段推进**：从 `prompts/` 里按顺序把提示词交给执行 AI，每到停顿点（SP1–SP5）停下自己审。每个阶段建议开一个新对话，靠进度看板交接。

## 阶段一览

| 阶段 | 内容 | 停顿点 |
| --- | --- | --- |
| P0 | 素材登记、环境与生图能力实测、3 秒技术测试 | — |
| P1 | 逐帧拆镜、姿态事件、图层、文字保护，分镜表对回叙事 | **SP1** 审分镜映射 |
| P2 | 画风规范、角色母版、双人对照，冻结 | **SP2** 审母版（最重要的一关） |
| P3-A | 难镜头动态样片（开场、杂耍、醒来、结尾） | **SP3** 审方法 |
| P3-B | 七类镜头分批生产，可并行 | — |
| P4 | 合并、全片组装、原音轨封装 | **SP4** 看全片结构 |
| P4s | 线条抖动与质感还原：先三个样镜，再分组并行推广 | **SP4s** 看质感全片 |
| P5 | 终稿小修与交付 | **SP5** |
