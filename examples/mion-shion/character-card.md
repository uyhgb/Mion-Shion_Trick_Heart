# 角色卡（最终版）：园崎魅音 / 园崎诗音

## 1. 参考素材（自备，未上传）

- **主身份源**：同一套游戏立绘。魅音用校服，诗音用白衬衫校服，诗音的便装只作身份辅助。每种表情都有闭嘴、半开、张开三张口型差分，正好对应原PV的张嘴事件。
- **CG**：作者逐张标注用途。鞋子细节看两张 CG；背面和侧面看一张两人同框的 CG（夜景，只看结构，不取色）；校服近景看一张。带伤、血、倒地的 CG 只用于标注的那一项用途。
- **取色**：只从立绘取。发色亮部约 `#46C490`，瞳色深部约 `#003F55`，两人相同。

## 2. 双胞胎原则（最高优先级）

| 项 | 规则 |
| --- | --- |
| 脸、瞳色、发色、身高 | 完全相同 |
| 区分手段 | 只靠发型（马尾 / 披发）、服装和表情演法 |
| 自检 | 遮住头发后，两张脸应该分不出谁是谁（用按双眼对齐的叠线来验证） |

## 3. 身份档案

**魅音**
- **发型**：高马尾，扎在后脑正中偏上，长度过腰；马尾出现在画面哪一侧取决于头的朝向；刘海带尖角，两侧鬓发短而翘。
- **气质**：爽朗、男孩子气，自称「大叔」，表情幅度大。

**诗音**
- **发型**：披肩长直发到腰；头两侧各系一个黄色小蝴蝶结，尾巴下垂。缎带的大小以第一版母版为准，不要收小。
- **徽章**：左胸有一枚红心徽章。
- **气质**：更「女孩子」，礼貌里带点狡黠。

**禁止水平翻转**：刘海和鬓发左右不对称，诗音的徽章在左胸，一翻转就错。

## 4. 服装

### 魅音：魔术师装 A1

结构照原PV（逐项核对过源帧）：
- 黑色高礼帽：白色菱形纹、红帽带、白羽毛。
- **长到臀部的红西装外套，没有燕尾**。
- 白手套配橙色翻袖口。
- 黑短裤。
- **腿部左右不对称**：她自己的右腿是黑白条纹过膝袜；左腿是到膝下的黑袜，大腿上另有一圈独立的腿环。
- 红短靴，靴口有白色锯齿翻边。

加入的魅音元素：淡黄马甲、红长领带（候选里还有领结版和深色外套版，作者选了长领带）；保留原PV的脸颊红心妆。

### 诗音：白衬衫校服

- 白色短袖衬衫，下摆自然散开。
- 藏青和灰色的斜条纹蝴蝶领结。
- 左胸红心徽章。
- 藏青短百褶裙。
- 黑色长筒袜到膝下，配棕色乐福鞋。

原PV散发角色的灰色开衫和结尾的黄外套，统一换成校服；结尾的斜挎包按源片保留。

**结尾变体**（s075–s077）：用一条黄缎带把头发扎成和魅音位置相同的高马尾，插上白羽饰，另一侧不系缎带。

## 5. 表情

源片的表情事件全部保留。演法只决定画法：
- **魅音**：咧嘴露齿、挑眉。
- **诗音**：抿嘴，笑意更多在眼睛里。

## 6. 简化后必须保留的身份标志

马尾的扎点和长度；两侧的黄色小蝴蝶结；蓝绿色瞳孔（不能画成テト的黑眼睛）；领结至少两三道斜条纹；左胸的小红心。

## 7. 母版历程（供参考）

1. **SP2**：作者选定服装 A1。
2. **SP2b**：返修。腿部改成照源片的不对称结构，删掉燕尾，统一两人共用的脸，画风再往扁平简笔收。
3. **SP2c**：魅音用第二版；诗音整套沿用第一版。按双眼对齐叠线后，诗音第一版和魅音第二版的脸型基本重合，只是瞳色偏浅、头约小 8%，这两点在逐镜制作时处理。双人合成图不单独重画，到逐镜生产时再画。
